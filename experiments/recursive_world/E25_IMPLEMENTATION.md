Fit persistent per-action dimensionless gain g, offset o and standardized output bias b from causally available observations. Design D=[J diag(a), J L, I], where J is finite-difference Jacobian of decoded frozen predictor normalized by official evaluation scale, L is action limit. Prior precision diag(1/.25^2). Accumulate P += D^T R^-1 D and h += D^T R^-1 r, solve P theta=h. Predict f(z,clip(a*(1+g)+L*o))+sigma*b. No simulator derivatives or fault labels at test. Six controls: unchanged trained predictor, unchanged last residual, calibrated scalar, output bias, actuator-only, joint. Use original CEM. Disjoint calibration seed base +1,000,000; source nominal residual RMS sets R (floor .02), scalar fitted on pooled consecutive calibration residuals.
