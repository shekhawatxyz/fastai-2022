# E13 frozen protocol — bidirectional semantic evidence
2026-11-25. Written before executing E13; no post-run edits to this protocol.
Question: can a new mechanic disambiguate the latent relationships explaining older mechanics, and can those relationships accelerate learning the new one?
Source text leads: Vakyapadiya 3.14.75 (abstraction of common meaning), 1.84 (earlier impressions), Patanjali's jnapaka (a clue is rejected when independently explained), Prabhakara/Shalikanatha's contextual meanings. These are inspirations, not ML claims.
World: all 64 scenes of two objects with three binary attributes each. Candidate predicates: 9 cross-object equalities and 9 cross-object conjunctions. Each world has actions A,B with hidden predicates and action C with one unknown binary composition (AND, OR, XOR). Two structured generators choose A,B from either equality or conjunction family; independent null draws C's predicates independently across the whole bank. Learner knows bank and possible compositions, not which family or latent IDs. No claimed discovery outside supplied primitives.
Data: 3 noisy observations each for A,B, then 0,1,2,4,8 for C; separate 16 test scenes shared across actions, remaining scenes for disjoint observed examples. Independent label flip probability .10, known to all learners. Seeds 8171, 9239, 200 worlds/family/seed; do not select seeds or adjust after seeing results.
Arms: target-only exact Bayes over same composition bank; MAP source transfer (locks source predicates); shared full joint posterior (same target predictions as exact source-informed transfer); robust mixture shared/independent (equal prior odds). Frozen source posterior is the no-backward-feedback comparison; robust backward update mixes revised and frozen source predictions. Exact joint inference is a strong baseline, not our novelty; compare it explicitly.
Metrics: exact binary next-state accuracy and Brier loss on untouched scenes; paired world-level bootstrap 95% intervals; CPU profiling. Predicted cells: candidate enumeration gives 18 predicates and 972 compositions; no observations produce normalized priors; posterior update preserves normalization and causal predictions; source evidence should aid C on structured families; C evidence should refine A/B; independent null should limit negative transfer.
Pre-run point predictions (percentage points; aspirational guesses not calibrated yet): robust minus target-only at 2 C exposures +8 on equality, +8 conjunction; robust backward minus frozen at 4 exposures +3 on each; independent robust minus target-only at 4 exposures -1. Gate: both structured families >=+5 forward and >=+2 backward, independent harm <=2, pooled paired 95% intervals exclude zero for both forward and backward gains. No GPU gate even if pass: must beat full-history relational inference or demonstrate cheaper inference at matched quality on real transitions. Report all results and failures.
